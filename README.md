# qfield-pnu-viewer

QField에서 지적 필지를 탭해 PNU를 확인하고, 브이월드 토지정보와 건축HUB 건축물대장을 카드로 조회하는 애플리케이션 플러그인입니다. 현재 메타데이터 버전은 **0.1.8**입니다.

## 설치 및 준비

1. QField에서 사용할 프로젝트에 지적 폴리곤 레이어를 포함하고, 필지별 PNU 속성값을 준비합니다. 플러그인은 PNU, pnu, Pnu, 필지고유번호, PIN, pin, PNU19, PNU_CD, PNU_CODE 필드 이름을 확인하며, 값은 숫자 19자리여야 합니다.
2. 프로젝트를 QField에 복사하거나 QFieldSync/QFieldCloud로 전달합니다. 프로젝트 CRS와 지적 레이어 CRS가 달라도 조회되는지 검증할 수 있도록, 우선 둘이 다른 테스트 프로젝트를 준비합니다.
3. QField 플러그인 설치 파일을 준비합니다. ZIP 안 최상위에 main.qml, metadata.txt, icon.svg가 있어야 합니다. 저장소에서 직접 패키징하는 경우 이 파일들을 플러그인 폴더의 루트에 둔 채 ZIP으로 압축합니다.
4. QField에서 **대시보드 → 설정(톱니바퀴) → 플러그인 → URL에서 플러그인 설치**를 선택하고 ZIP의 직접 다운로드 URL을 입력합니다. 설치된 플러그인을 활성화하고, 최초 실행 시 표시되는 권한 요청을 허용합니다.
5. 프로젝트를 열고 지도에 플러그인 버튼이 나타나는지 확인합니다.
6. 플러그인 설정에서 **브이월드 API 키**와 **건축HUB API 키**를 입력하고 저장합니다. 두 키는 각 서비스에서 발급받아야 합니다. 조회할 때 기기의 인터넷 연결이 필요합니다.

## 빠른 검증 체크리스트

아래 항목을 순서대로 한 번씩 확인합니다.

- [ ] **설치·실행:** 플러그인이 목록에 설치되고 활성화되며, 프로젝트를 열었을 때 플러그인 지도 버튼이 표시됩니다.
- [ ] **필지 선택:** 플러그인 버튼을 누른 뒤 대상 필지를 한 번 탭하면 선택 정보 창이 열립니다.
- [ ] **PNU 인식:** 토스트와 창에 해당 필지의 19자리 PNU 및 레이어명이 표시됩니다. PNU가 앞자리 0을 포함해 원래 문자열 그대로 유지되는지 확인합니다.
- [ ] **CRS 처리:** 프로젝트 CRS와 지적 레이어 CRS가 다른 상태에서도 동일한 필지를 선택할 수 있습니다. 가능하면 두 CRS 설정에서 같은 필지의 PNU가 동일한지 비교합니다.
- [ ] **토지 카드:** 토지이용계획을 눌러 토지 기본정보(소재지·지번·지목·면적 등)와 지역·지구 지정내역 카드가 표시되는지 확인합니다.
- [ ] **건축물 카드:** 건축물대장을 눌러 결과 카드가 표시되는지 확인합니다. 건물이 없는 필지는 “표제부를 찾지 못했습니다”가 정상적인 무결과일 수 있습니다.
- [ ] **구버전 QField:** 실제 배포 대상 중 가장 오래된 QField 버전에서 플러그인 활성화, 필지 선택, CRS가 다른 레이어 조회를 각각 확인합니다. 최신 버전에서의 성공만으로 구버전 호환을 판정하지 않습니다.

**통과 조건:** 버튼이 나타나고, PNU가 맞으며, 두 조회 버튼이 각각 성공 결과 또는 명확한 무결과/오류 상태를 표시해야 합니다. API 서비스에 해당 필지 데이터가 없는 경우에는 카드에 오류 또는 결과 없음이 표시될 수 있으므로 이를 플러그인 설치 실패와 구분합니다.

## 문제 발생 시 점검 순서

1. **플러그인 버튼이 없음** — 플러그인 설치 여부와 활성화 스위치, 첫 실행 권한 허용 여부를 확인합니다. 프로젝트를 다시 연 뒤 잠시 기다리고 버튼을 다시 확인합니다.
2. **필지 탭이 동작하지 않음** — 지적 레이어가 프로젝트에 포함되고 표시되는지 확인합니다. 플러그인이 인식하는 이름은 LSMD_CONT_LDREG - pnu 결합, LSMD_CONT_LDREG - pnu결합, LSMD_CONT_LDREG입니다. 레이어명과 필드명을 확인하고, 다른 도형이 겹치지 않는 필지 내부를 탭해 봅니다.
3. **필지를 찾았지만 PNU를 못 읽음** — PNU 필드의 값이 null/빈 값이 아닌지, 숫자 19자리인지 확인합니다. 엑셀에서 가져온 값이 지수 표기 또는 반올림된 값이면 원본 문자열로 복구해야 합니다. PNU는 숫자 형식보다 문자열 형식으로 보존하는 것이 안전합니다.
4. **CRS가 다른 경우에만 선택 실패** — QGIS에서 프로젝트 CRS와 지적 레이어 CRS가 올바르게 지정되어 있는지 확인합니다. 0.1.8은 화면 좌표를 레이어 좌표계로 변환하는 CRS-aware 조회를 포함하지만, 실제 구버전 QField에서는 지원 여부를 별도로 시험해야 합니다.
5. **토지이용계획 카드 실패** — 브이월드 키가 저장되었는지, 키의 사용 설정/허용 도메인 및 잔여 호출량, 기기 인터넷 연결을 확인합니다. 토지 기본정보와 지정내역은 각각 조회되므로 한 카드만 실패할 수도 있습니다.
6. **건축물대장 카드 실패** — 건축HUB 키가 저장되었는지 확인합니다. 공공데이터포털 인증키는 URL 인코딩된 키와 복호화 키 입력을 혼동하지 않았는지 확인하고, 연결·서비스 이용 상태와 해당 지번의 표제부 존재 여부를 점검합니다.
7. **구버전에서 플러그인이 켜지지 않거나 선택 오류 발생** — QField 버전과 기기 OS를 기록하고, 대상 구버전에서 재현 여부를 확인합니다. 0.1.8은 org.qfield.core 의존 import를 제거하고 GeometryUtils / LayerUtils 경로를 사용하도록 조정했지만, 저장소에는 최소 지원 QField 버전이나 기기별 검증 결과가 명시되어 있지 않습니다. 따라서 특정 구버전 지원은 실제 기기 검증을 통과한 버전만 기록합니다.

오류 제보 시 QField 버전/OS, 프로젝트 CRS와 지적 레이어 CRS, 레이어명, PNU 필드명(실제 PNU 값과 API 키는 제외), 수행 단계, 화면에 표시된 오류 문구를 함께 남겨 주세요.
